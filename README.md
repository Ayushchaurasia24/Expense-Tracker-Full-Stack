## 🚀 Deployment Note

This project was previously deployed on AWS EC2 with a CI/CD pipeline 
using Jenkins and PM2. It has since been taken offline as part of 
infrastructure cost optimization — the same EC2 instance is now 
dedicated to serving a more recent production project, 
[ChatNexus](https://chat-nexus-six.vercel.app).

The complete source code is available here for reference.
All features are fully functional in a local environment.
